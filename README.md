# Hub
The implementation of the hub server

Developed by Choukas.

## Requirements
The following items are required to run the server :
- Java 21
- Git

## Run the server
1. Open a terminal and clone this repository using `git clone https://github.com/pandoniamc/hub.git`
2. Navigate to the project folder though `cd hub`
3. Build the project (`./gradlew build`)
4. Navigate to the built .jar file using `cd build/libs`
5. Run the .jar file (`java -jar hub-1.0-SNAPSHOT.jar`)

The server will be available as `localhost:25565`.
